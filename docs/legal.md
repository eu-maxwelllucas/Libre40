# Legal And Distribution Policy

This repository is for original project code, dependency notes, ReXGlue configuration, and contributor documentation only.

Users must provide their own legally obtained compatible copy of Army of Two: The 40th Day for Xbox 360. Do not upload, request, link, or describe sources for unauthorized game files.

Do not commit ISO files, XEX/XEXP files, extracted title data, PE images, private binary dumps, save data from retail profiles, generated ReXGlue C++ output produced from a retail binary, keys, cracks, bypasses, or download links.

Each user runs extraction and ReXGlue codegen locally against their own legal copy.
